# Known limitations

- The .NET Framework fallback uses .NET Framework 4.8 or later and omits the hardware sensor library and FPS capture executable. GitHub Actions builds and tests the standard self-contained installer.
- Startup Registry Run values and common Startup entries are visible as registrations. Use Windows Startup Settings for their enabled state and changes. In-app backup and restore cover eligible current-user `.lnk` entries. Publisher details come from executable version metadata and can be blank.
- Browser cleanup covers conventional Chrome, Edge and Firefox profile paths and the supported disposable cache subfolders. Custom profile directories outside known roots are excluded. Internet Explorer and other browsers are outside scope.
- Windows Update and Delivery Optimization cleanup open Windows Storage settings. Thumbnail cache files in use may be skipped. Recycle Bin totals come from Windows before and after and may change if another process modifies its contents.
- Memory pressure uses available RAM, commit headroom, Windows memory-load reporting and the Windows low-memory signal. Automatic working-set trimming is limited to AKASS by default or one explicitly approved idle background app per session. The manual standby-list operation depends on Windows support and administrator approval. Paging-rate analytics, automated closing, and drive media detection are outside scope.
- Temperature readings depend on exposed hardware sensors and driver permissions. GPU temperature shows the hottest detected adapter. FPS depends on PresentMon observing the foreground application's displayed frames. The topmost overlay works in windowed/borderless mode and may be hidden by exclusive fullscreen games.
- Repairs capture output and exit status at completion. While a repair runs, progress is indeterminate. The generated Windows battery report depends on Windows and hardware support.
- The UI is localized for the three supported languages. Windows tool output, some detailed runtime errors, and some exported diagnostic fields can remain in their original language.
- The portable archive requires extraction of the complete contents. Independent Windows 10, DPI, scheduled task, game FPS, hardware sensor, live battery and elevated repair validation remain machine-dependent.
